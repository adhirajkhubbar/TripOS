# TripOS — Travel Operating System

A polished frontend-only travel planning portfolio project built with React + Vite.

## Stack
- React + Vite
- React Router
- Lucide React
- Responsive CSS
- LocalStorage persistence
- No Python
- No MongoDB
- No backend
- No Gemini or external AI integration

## Run
```bash
npm install
npm run dev
```

If port 5173 is busy, Vite will automatically use another port.

## Features
- Responsive dashboard and mobile drawer
- Trip switcher and trip creation
- Itinerary builder with add/delete actions
- Timeline and map-style planner views
- Local route checks and packing-list actions (no API required)
- Destination discovery with favorites
- Budget tracker and expense modal
- Search overlay
- Dark/light mode
- LocalStorage persistence
- Export itinerary as JSON
- Share/copy trip summary
- Reset local demo workspace
- Fully functional navigation and buttons
